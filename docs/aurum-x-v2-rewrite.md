# AURUM X — بازنویسی کامل نسخه دوم

این شاخه، محیط مستقل بازنویسی است. شاخه `main` تا زمان تکمیل و آزمون نسخه جدید دست‌نخورده می‌ماند.

## الزام‌های صریح فعلی

### تایم‌فریم‌ها
- پشتیبانی از ۱m، ۳m، ۵m، ۱۵m، ۳۰m، ۱h و ۴h.
- انتخاب آزاد هر ترکیب غیرخالی، از یک تایم‌فریم تا همه.
- فقط تایم‌فریم‌های انتخاب‌شده دریافت و تحلیل شوند.
- تحلیل هر تایم‌فریم مستقل باشد و انتخاب یک تایم‌فریم برای تحلیل و صدور سیگنال مستقل کافی باشد.
- مبنای هر تحلیل آخرین کندل کاملاً بسته‌شده همان تایم‌فریم باشد.
- داده تایم‌فریم‌های انتخاب‌نشده نباید وارد تصمیم شوند.
- در انتخاب چند تایم‌فریم، همه باید هم‌جهت باشند؛ اختلاف یا نبود تأیید روشن در هرکدام، خروجی بدون سیگنال است.
- هیچ الزام به هم‌زمانی بسته‌شدن کندل‌ها یا هم‌ردیفی timestampها وجود ندارد.

### رابط کاربری
- بازطراحی بصری با کیفیت گرافیکی بالا، سبک مشکی/طلایی و چیدمان واکنش‌گرا برای اندازه‌ها و تراکم‌های مختلف نمایشگر.
- «4K» هدف کیفیت طراحی و دارایی‌های گرافیکی است؛ رابط باید با وضوح واقعی دستگاه تطبیق پیدا کند و نباید رزولوشن نمایشگر را جعل یا به 4K قفل کند.

## اصول اجرای بازنویسی
1. پیاده‌سازی در همین شاخه مستقل؛ عدم تخریب نسخه اصلی.
2. جداسازی domain، data، analysis، notifications، background service و presentation.
3. حذف وابستگی‌های متقاطع و قرار دادن قراردادهای مشترک در ماژول‌های کوچک و تست‌پذیر.
4. آزمون واحد برای سیاست تایم‌فریم، بسته‌بودن کندل و اجماع جهت‌ها.
5. اجرای تست‌های Python و Android و ساخت APK قبل از ادغام.
6. تا وقتی کل مسیر از دریافت داده تا رابط و اعلان در دستگاه آزمایش نشده، بازنویسی «کامل‌شده» اعلام نمی‌شود.

## وضعیت
- شاخه مستقل ایجاد شده است.
- قرارداد پایه انتخاب تایم‌فریم و آزمون‌های اولیه آن اضافه شده‌اند.
- این سند فهرست کارهای باز است، نه ادعای تکمیل بازنویسی.
